# 学习资料区（learning/）

这里只放**学习笔记与资料整理**，不放可运行代码。

| 子目录 | 用途 | 记什么 |
| --- | --- | --- |
| `competition-notes/` | 比赛研究 | 官网规则、评分公式、难度分级、时间线、榜单观察、他人方案分析 |
| `basics/` | 基础知识 | ReAct / Function Calling / Text2SQL / 文档理解 / Agent 设计模式，一主题一文件 |
| `baseline-study/` | 源码精读 | 逐模块拆解官方 starter kit：agent 循环、工具系统、prompt、评测 |
| `experiments-log/` | 实验日志 | 每次跑实验的配置、结果、失败归因（用 `template.md` 复制新建） |
| `resources/` | 外部收藏 | 论文链接+一句话摘要、优质博客、官方 Discord 的有价值信息 |

## 写笔记的建议

1. 文件名用编号前缀排序：`01-xxx.md`、`02-xxx.md`；
2. 每篇笔记开头写三行：**是什么 / 为什么重要 / 和比赛的关联**；
3. 读源码笔记务必带 `文件路径:行号`，方便回跳；
4. 实验日志当天写完当天提交，宁可粗糙不可拖延。
