## 2. 归因三分法

把每题归入一类，先分类再想对策：

| 类别 | 定义 | 题数（待填） | 典型对策 |
| --- | --- | --- | --- |
| 未提交 | 没产出答案（步数耗尽 / 崩溃 / 解析彻底失败） | | 提高步数上限、加固解析、加兜底输出 |
| 提交但全错 | 有答案但 0 分 | | 检查是否理解错题意、列内容是否算错 |
| 部分正确 | 命中部分列 | | **列形状校验**：多给列 / 少给列 / 列内容偏差 |
