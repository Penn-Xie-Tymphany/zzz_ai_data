# 补丁记录：我为跑通环境改过什么

> **是什么**：本机为适配自己的 LLM 后端 / 系统环境，对官方 starter kit 源码做的修改清单。
> **为什么重要**：官方代码是快照入库的，重克隆或换机器时**没有这些补丁就跑不起来**。
> **和比赛的关联**：补丁属于环境适配，不算方案改进，跑分对比时要保证双方环境一致。

> ⏳ **待补写**：每打一个补丁就记一条。规则：**改一行，记一行**。

## 常见的几类补丁（供对照）

- [ ] **编码问题**：Windows 下读文件/写产物报 `UnicodeDecodeError` / `UnicodeEncodeError`
- [ ] **JSON 解析**：模型输出带 Markdown 代码 fences 或尾随逗号，需要宽容解析
- [ ] **子进程死锁**：用 `PIPE` 捕获输出但不读，长时间挂起（见 [../basics/05-Python并发基础.md](../basics/05-Python并发基础.md)）
- [ ] **超时与重试**：后端限流/超时，需要退避重试
- [ ] **路径分隔符**：硬编码 `/` 在 Windows 上的兼容处理
- [ ] **请求体超限**：超长 observation 导致 413，需要截断/摘要

## 纪律

1. 补丁要**最小改动 + 集中记录**，避免与官方代码混成一片难以升级；
2. 改到可能影响分数的逻辑，必须在 [全量跑分复盘.md](全量跑分复盘.md) 里注明；
3. 任何补丁都**不得引入密钥明文**（见根 `AGENTS.md` §3）。
