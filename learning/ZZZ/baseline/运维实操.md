> **和比赛的关联**：跑分数字是唯一硬指标，跑法必须固定下来。

## 1. 环境准备

```powershell
# starter kit 已随仓库 clone：code/competitions/kddcup2026-data-agents-starter-kit/
# 数据集需自行下载解压（见 code/competitions/datasets/README.md）

powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
$env:Path = "$env:USERPROFILE\.local\bin;$env:Path"
cd code\competitions\kddcup2026-data-agents-starter-kit\PHASE_1
uv sync
```

## 2. 配置 LLM

- 复制 `configs/` 下的 `.example.yaml` 为自己的配置，填 model / api_base / api_key；
- **api_key 只留本地**：配置文件不入库（见根 `AGENTS.md` §3）。

## 3. 验证与跑题

```powershell
uv run dabench status --config <我的config.yaml>            # 期望 Public tasks: 50
uv run dabench run-task task_11 --config <我的config.yaml>   # 单题验证
uv run dabench run-benchmark --config <我的config.yaml>      # 全量，跑完自动出分
uv run dabench evaluate <run_id> --config <我的config.yaml>  # 复盘历史 run（不调模型）
```

- 单题产物：`artifacts/runs/<run_id>/`（含 `prediction.csv`）；
- 全量报告：`artifacts/runs/<run_id>/evaluation_report.json`。
