## 半钟速览顺序（新人起步版）

1. **basics**：先看 [比赛总览.md](basics/比赛总览.md) 搞清"题长什么样、怎么算分"，再按 01~05 顺序补齐通用地基；

3. **agent**：等自研有实质进展后再开始读。
