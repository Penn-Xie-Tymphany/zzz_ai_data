## 卡片速览

- **一句话**：官方 baseline 是一个"零框架"的 ReAct agent，用 8 个工具 + LLM 逐题推理，产出 `prediction.csv`。
- **架构**：思考简单、工具强劲、评测独立。见 架构总览.md 的三张图。
- **成绩**：demo 实测 micro≈0.376；推理越强模型，分越高。
